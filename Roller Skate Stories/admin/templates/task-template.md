# Task Template

Use this for every task that gets assigned to a contributor.

```markdown
## Task

**Title:** Short, clear action  
**ID:** RSS-YYYY-MM-DD-### (auto-increment or manual)

## Details

- **Lane:** (Movement / Media / Merch / Music / Events / Positivity)
- **Requester:** (who asked for this)
- **Owner:** (who will do this)
- **Due date:** YYYY-MM-DD
- **Estimated time:** e.g., 2 hours, 1 evening, per shoot
- **Priority:** Low / Medium / High / Blocking

## Description

What needs to be done. Be specific enough that the owner can start without asking questions.

## Definition of done

- [ ] Criterion 1
- [ ] Criterion 2
- [ ] Criterion 3

## Resources / links

- Relevant file, folder, link, or contact

## Notes

Any extra context, risks, or questions.
```

### Example

```markdown
## Task

**Title:** Capture 10 photos at Skateland Chandler adult night  
**ID:** RSS-2026-11-10-001

## Details

- **Lane:** Media
- **Requester:** Milton Young
- **Owner:** [Contributor name]
- **Due date:** 2026-11-12
- **Estimated time:** 1 evening (2–3 hours)
- **Priority:** Medium

## Description

Attend Skateland Chandler adult night on Tuesday, Nov 10. Capture candid photos of skaters, the vibe, and any notable moments. Aim for at least 50 raw shots; we will cull to 10–15 for social.

## Definition of done

- [ ] Photos uploaded to the shared RSS media folder by Nov 12
- [ ] Top 15 favorites starred or flagged
- [ ] Brief note on any people/stories worth following up

## Resources / links

- Media folder: [link]
- Adult night time: 7:00–10:00 PM

## Notes

Ask skaters before close-up shots. If someone declines, respect it and move on.
```
