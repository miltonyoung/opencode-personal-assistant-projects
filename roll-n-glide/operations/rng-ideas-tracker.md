# Roll N Glide — Ideas & Growth Tracker

**Purpose:** Give community ideas a clear home, track their status, and show contributors their input gets used.

---

## How to use this tracker

- **Submitted By:** Record name or @handle if they want credit.
- **Category:** Activity / Theme / Workshop / Growth / Other.
- **Status:**
  - `New` — just submitted, not yet reviewed
  - `Considering` — discussed by the team, possible fit
  - `Used` — implemented at an event
  - `Deferred` — good idea, but not the right time
- **Notes / How It Helps Growth:** Briefly explain why the idea matters and how it builds community.
- **Follow-Up:** Action or event where it was/will be used.
