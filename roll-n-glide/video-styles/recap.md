# Rolling Glide — Recap Video Style

## Purpose

Evoke belonging, joy, and "I want to be there." Show Rolling Glide as an inclusive, smooth, helpful skate community where people come to skate and stay for the connection.

## Brand anchors

- **Vibe:** "Sunset Soul" — festival energy + family-reunion safety
- **Analogy:** "The Salsa Social on Wheels"
- **Core words:** Flow, Vibe, Connect, Safe Space
- **Music genre:** Neo-Soul / R&B; smooth, in the pocket, never aggressive
- **Guardrails:**
  - DO: inclusive, helpful, inviting, smooth, sensual (in rhythm)
  - DON'T: judgmental, disconnected, intimidating, sexual/provocative

## Footage rules

- **Source:** One event date's folder by default.
- **Format:** Prefer vertical 9:16. Horizontal clips (e.g., drone) are cropped and reframed to keep subjects centered; keep multiple people in frame when possible.
- **Color:** Clips may be log or already graded. Log clips get a default Rec.709 LUT during draft render. Graded clips pass through unchanged.
- **Intake:** Source folder = log unless placed in `exports/` or `graded/` subfolder.

## Shot priority

- **75% social joy:** faces, laughter, eye contact, high-fives, groups, people skating together, learning together.
- **25% technical connection:** close-ups of clasped hands, synchronized skates, spins.
- **Avoid:** falls, embarrassment, anything that makes someone look bad.

## Pacing and rhythm

- **Target length:** ~30 seconds; up to 60 seconds if the event was rich.
- **Clip length:** Short; use only the best part of each source clip.
- **Pacing follows the song:**
  - Upbeat track → quick cuts, high energy.
  - Slower R&B track → longer clips, let moments breathe.
- **Cuts land on music beats**, varied so the viewer feels like they are "riding the beat."
- **Slow motion:** used on beat, often for spins or peak moments, then transition out. Often used as the final shot.

## Structure options

Default to chronological unless specified otherwise.

1. **Chronological** — beginning, middle, end of the event.
2. **Wide → close → wide arc** — start wide, move to close-ups, finish wide.
3. **Peak-first** — open with the strongest moment, then show how you got there.
4. **Energy montage** — no story, pure vibe.

## Transitions and effects

- **Common transitions:** hard cuts, crossfades, zoom in/out.
- **Effects:** light leaks and lens flares used sparingly, not on every cut.
- **Speed ramps:** occasional.
- **CapCut pass allowed:** pipeline produces a solid draft; CapCut can be used for proprietary transitions if desired.

## Branded elements

- **Persistent logo:** Rolling Glide logo in bottom right corner throughout the reel.
- **Optional intro/outro:** logo zooms in while fading out before it fills the screen.
- **Text:** usually none for a pure recap.
- **Optional CTA:** end with text like "Next one [date]" or "Come skate with us" if the recap also serves as an announcement.

## Music

- **Platform-first strategy:** for Instagram/TikTok, Milton may provide a screen recording of a trending song. The system uses the recording for timing/energy shaping. The final upload uses that same song selected inside the platform to avoid copyright issues.
- **Artlist library:** for non-platform-native exports, pull from local Artlist library of Neo-Soul / R&B tracks.
- **Upbeat recaps:** "Nuala bounce" style or similar energetic tracks.
- **Vocals:** allowed.

## Output specs

- **Format:** vertical 9:16
- **Resolution:** 1080×1920 minimum
- **Platforms:** Instagram Reel (primary), cross-posted to TikTok
- **Fallback:** occasionally a shorter Story version

## Post-pipeline handoff

The system outputs:
1. A reference render MP4 with default LUT applied (if needed).
2. A Resolve-compatible EDL/timeline pointing to the original selected source clips.
3. A notes file listing which clips are log vs. graded.

Milton opens the timeline in DaVinci Resolve for final color grading, CapCut pass (if desired), and platform upload.

## Iteration notes

This is the first style template. Milton has not yet iterated with an AI-assisted draft, so all dimensions should be easy to override in the first few renders until he learns what he typically wants to change.
